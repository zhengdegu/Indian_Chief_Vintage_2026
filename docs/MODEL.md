# 网页模型

文件：`public/models/chief-vintage.glb`。模型基于公开照片与官方尺寸进行外观重建，供展示使用，不是厂商 CAD 或机械运动仿真。

| 项目 | 数值 |
|---|---|
| 文件大小 | 3,907,000 字节，约 3.9 MB |
| 三角形 | 535,841 |
| glTF 网格 | 44 |
| 材质批次 | 46 |
| 材质 | 41 |
| 内嵌图像 | 5 |
| 压缩 | Draco，浏览器使用本地解码器 |
| 单位与朝向 | 米；+Y 向上、+X 车头、+Z 骑手右侧 |

完整导出统计见 [`model-info.json`](../public/models/model-info.json)。

网页模型由原始可编辑 Blender 工程导出：求值修改器，合并静态材质批次，保留双色挡泥板和油箱图形的 UV；程序材质转换为 PBR，其中皮革保留法线纹理。网页模型可在 glTF 兼容工具中打开，但其对象组织已针对实时渲染优化，原始 Blender 工程不包含在本仓库中。

导出曾重新解码、导入独立 Blender 进程、渲染并检查；浏览器亦完成实际加载与多视角查看。轮廓和外观来自真实照片及尺寸，隐藏结构及部分曲面是照片推定。
